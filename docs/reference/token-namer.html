Component token namer

Pattern: component / category / role / state. Colour only.

One word if possible. Spaces and capitals are stripped, so "Icon button" becomes iconbutton.

Category

Which part of the component is painted.

Role

Leave all unselected if the component has only one variant. The role segment is then omitted.

State

Default is always included and cannot be removed.

Figma group

Top-level group the variables sit under.

Every combination is on by default. Untick the ones that do not exist on this component.

Map each token to a primitive for both modes. Publishing follows the rule: default states published, all other states hidden.
